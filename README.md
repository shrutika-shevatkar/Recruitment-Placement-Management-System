# Recruitment and Placement Management System

## Project Description
This project manages student registration, company details, offers, interviews and placements.

## Technologies Used
- Java
- MySQL
- JDBC
- Maven

## Modules
1. Student Management
2. Company Management
3. Offer Management
4. Interview Management
5. Placement Management

## Features
- Add student details
- Manage company details
- Manage job offers
- Schedule interviews
- Track student placements

## Database
Database Name: rpms
